# חדר בריחה — בחירות 2026

משחק חדר-בריחה אזרחי אינטראקטיבי, בנוי כאוסף קבצים סטטיים (HTML/CSS/JS ללא build step).
פשוט פתחו את `index.html` דרך שרת מקומי (או ארחו בכל אחסון סטטי — GitHub Pages, Netlify וכו').

הרצה מקומית מהירה:
```
cd escape-room
python3 -m http.server 8080
# ואז פתחו http://localhost:8080
```
(חובה שרת — לא ניתן לפתוח את הקובץ ישירות מה-Finder/Explorer, כי טעינת מודולי ה-JS דורשת http.)

## העלאה ל-GitHub

הפרויקט קטן ונקי מספיק (כ-31MB סה"כ, שום קובץ בודד מעל 15MB) כדי לעלות ישירות ל-GitHub בלי Git LFS ובלי צמצום נוסף. מהתיקייה `escape-room`:
```
git init
git add .
git commit -m "חדר בריחה — בחירות 2026"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
(במקום USERNAME/REPO-NAME שימו את שם המשתמש והריפו שיצרתם ב-GitHub. אם עדיין אין ריפו — צרו אחד ריק ב-GitHub קודם, בלי README/gitignore אוטומטיים, כדי שהפקודות למעלה יעבדו חלק.)

לאחר ההעלאה, אפשר גם להפעיל **GitHub Pages** (הגדרות הריפו → Pages → Deploy from branch → `main` / root) כדי לקבל קישור ציבורי חי למשחק, בלי צורך באחסון חיצוני נוסף.

## עיצוב

- **גופן:** Open Sans בכל האפליקציה.
- **רקע:** תמונת הרקע שסופקה (`assets/images/background.jpg`) ממלאת את כל המסך; חלון המשחק צף מעליה כזכוכית מטושטשת (glassmorphism) עם אנימציית ריחוף עדינה.
- **רספונסיבי:** מובייל (ברירת מחדל, "מסגרת טלפון") ומחשב (מ-900px ומעלה, פריסת "קונסולה" עם סרגל צד קבוע ובמה רחבה) — עובר אוטומטית לפי רוחב המסך.
- **חגיגת הצלחה:** על כל תשובה נכונה קופצת שקופית עם וי ירוק וקונפטי קטן; בסיום המשחק — קונפטי מלא ותעודת גמר.

## סרטוני פתיחה קופצים (video popups)

`js/ui.js` מייצא `showVideoPopup({ media, title, caption, onDismiss })` — חלונית שקופצת מעל כל מסך, מנגנת סרטון אוטומטית (מקומי או YouTube), ונסגרת בלחיצת כפתור "עצירת הסרטון והמשך". שני מקומות משתמשים בה כרגע:
- **לפני התחנה הראשונה**: קופצת מיד אחרי ההרשמה, מעל מפת השלבים (`main.js`, `INTRO_VIDEO`). שעון המשחק מתחיל לרוץ רק אחרי שסוגרים אותה.
- **תחנה 19 (מפלגת הפיראטים)**: קופצת אוטומטית עם פתיחת התחנה, לפי השדה `meta.popupVideo` בקובץ `station19.js`. יש גם כפתור "צפו שוב בסרטון" בתוך התחנה שפותח אותה מחדש בכל רגע.

כדי להוסיף סרטון קופץ לתחנה נוספת: הוסיפו ל-`meta` שלה `popupVideo: { type: 'video', src: '...' }` (או `{ type: 'youtube', id: '...' }`) — `main.js` יזהה ויציג אותו אוטומטית עם פתיחת התחנה.

**לגבי סאונד:** לסרטון מקומי המערכת מנסה לנגן עם קול; אם הדפדפן חוסם זאת (מדיניות אוטופליי, בעיקר ב-Safari) — עוברת אוטומטית לניגון מושתק עם רמז ללחוץ ולהפעיל קול. סרטוני YouTube תמיד מתחילים מושתקים (כך מבטיחה מדיניות הדפדפנים שהם תמיד יתנגנו אוטומטית) — יש כפתור השתקה/ביטול השתקה מובנה בנגן של יוטיוב עצמו.

## הערה חשובה — תחנה 19 (מפלגת הפיראטים)

לא הייתה לי דרך לוודא איזו רשימת מפלגות בפועל מתמודדת ב"בחירות הנוכחיות" הפיקטיביות של התרחיש (זו כבר עובדה שהומצאה לצורך התרגיל, כמו 38 המפלגות ו-70.6% ההצבעה). קבעתי תשובה זמנית (`CORRECT_ANSWER = 'yes'`) בראש הקובץ `js/stations/station19.js` — שנו אותה בקלות לפי מה שמתאים לתרחיש שלכם, ושימו קובץ וידאו בנתיב `assets/video/station-19.mp4`.

## סאונד

`js/audio.js` בודק קודם אם קיימים קבצי שמע אמיתיים בתיקייה `assets/audio/` (mp3), ומנגן אותם.
אם קובץ חסר — נופל אוטומטית לגרסה סינתטית עשירה (אנוולופים, קליקים מבוססי רעש מסונן, אקורדים וריברב קצר, לא "ביפים" פשוטים).
כדי להשתמש בסאונד אמיתי, שימו קבצים בשמות הבאים בתוך `assets/audio/`:
```
tick.mp3, select.mp3, toggle.mp3, success.mp3, error.mp3,
hint.mp3, unlock.mp3, victory.mp3, countdown-step.mp3, countdown-go.mp3,
bg-music.mp3, victory-music.mp3
```
כל קובץ הוא אופציונלי בפני עצמו — אפשר להוסיף רק חלק מהם וההיתר יישארו בגרסה הסינתטית.

## פתיחה: 4 שניות רקע + מוזיקה

כשהאתר עולה, חלון המשחק (app-shell) שקוף לגמרי למשך 4 שניות — כך שרואים רק את תמונת הרקע לפני שהוא נחשף (`main.js`, `SPLASH_DELAY_MS`). באותו רגע גם מתחילה לנגן **מוזיקת רקע שמחה וקצבית**, שממשיכה ברקע לאורך כל המשחק, ועוברת **למוזיקת ניצחון** במסך התעודה בסוף.

כמו עם הצלילים, המנוע מחפש קודם קבצים אמיתיים — אם תשימו `assets/audio/bg-music.mp3` (לולאה) ו/או `assets/audio/victory-music.mp3` הם ינוגנו. בלעדיהם, `js/audio.js` מייצר לבד לולאת רקע (פרוגרסיית אקורדים מז'ורית שמחה I-V-vi-IV עם ארפג'יו וקצב) ופאנפרה גדולה לניצחון — לא רק צליל בודד.

**מגבלת דפדפנים חשובה:** אף דפדפן לא מרשה ניגון קול אוטומטי *לפני* שהמשתמש לוחץ על משהו בעמוד. לכן המוזיקה "מותחלת" מיד עם טעינת האתר, אבל בפועל תישמע רק אחרי הלחיצה/הקשה הראשונה של התלמידים בעמוד (למשל כשהם לוחצים על שדה שם הקבוצה) — זה קורה כמעט מיד, ולא דורש שום פעולה נוספת מכם.

## הוספת תמונה או סרטון לתחנה

בכל קובץ `js/stations/stationXX.js` יש שדה `meta.media`, לדוגמה:
```js
media: { type: 'image', src: 'assets/images/station-01.jpg' },
```
שימו קובץ בשם הזה בתוך `assets/images/` — הוא יופיע אוטומטית בראש כרטיס התחנה (ובתצוגת מחשב — כפאנל לצד התוכן).
לסרטון: `media: { type: 'video', src: 'assets/video/station-19.mp4' }` (מתנגן בלולאה, ללא קול).
אם הקובץ לא נמצא, מוצג אוטומטית אייקון חלופי אלגנטי — אין צורך לדאוג לקריסה.

## הוספת תחנה חדשה

1. העתיקו קובץ תחנה קיים (למשל `station20.js`) לשם חדש.
2. עדכנו את `meta` (כותרת, טקסטים, ניקוד, אייקון) ואת פונקציית `mount` — הכי קל לבחור אחד מהווידג'טים הקיימים ב-`js/widgets.js`.
3. הוסיפו ייבוא וערך למערך ב-`js/stations/index.js`.
זהו — המפה, הניקוד וההתקדמות מתעדכנים אוטומטית (הניקוד הכולל תמיד שווה בדיוק ל-100, מחולק שווה בשווה בין כל התחנות).

## מה לא כלול (בכוונה, בשלב הזה)

דשבורד מורה וחיבור לשרת (שמירת תוצאות קבוצות, מעקב בזמן אמת וכו') **לא** נבנו בשלב הזה —
נשמח לתכנן ולהוסיף את זה כשלב הבא, כולל בחירת backend (Firebase / Google Sheets / שרת ייעודי).
